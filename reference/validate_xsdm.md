# validate xsdmbayes_object constructed via xsdmbayes_plus function

validate xsdmbayes_object constructed via xsdmbayes_plus function

## Usage

``` r
validate_xsdmbayes(xsdmbayes_object)
```

## Arguments

- xsdmbayes_object:

  An xsdmbayes object constructed with new_xsdmbayes function

## Value

A validated xsdmbayes_object
