# Get loo from xsdmbayes model

Get loo from xsdmbayes model

## Usage

``` r
loo(xsdmbayes_object, index = 1, ...)
```

## Arguments

- xsdmbayes_object:

  an xsdmbayes object created with constuctor and validated

- index:

  An integer ginving the row index from the sample

- ...:

  argument passed to stan model sampling

## Value

a fitted xsdmbayes object
