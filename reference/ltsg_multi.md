# Multivariate long term stochastic growth function for a Lewontin Cohen demographic environmental model

Multivariate long term stochastic growth function for a Lewontin Cohen
demographic environmental model

## Usage

``` r
ltsg_multi(env, mu, sigl, sigr, L)
```

## Arguments

- env:

  Matrix Environmental time series (columns) per sites (rows)

- mu:

  numeric parameter.

- sigl:

  numeric parameter.

- sigr:

  numeric parameter

- L:

  matrix parameter
