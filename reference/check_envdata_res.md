# Check environmental data list resolution Check if all elements in the env_data list have equal resolution

Check environmental data list resolution Check if all elements in the
env_data list have equal resolution

## Usage

``` r
check_envdata_res(envData)
```

## Arguments

- envData:

  An list with environmental data time serires as elements.

## Value

If all the raster time serires are the same, return the crs string. If
not returns FALSE
