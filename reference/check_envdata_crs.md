# Check environmental data list coordinate reference system Check if all elements in the env_data list have equal coords

Check environmental data list coordinate reference system Check if all
elements in the env_data list have equal coords

## Usage

``` r
check_envdata_crs(envData)
```

## Arguments

- envData:

  An list with environmental data time serires as elements.

## Value

If all the raster time serires are the same, return the crs string. If
not returns FALSE
