# Constructor function for the class xsdmbayes

Constructor function for the class xsdmbayes

## Usage

``` r
new_xsdmbayes(
  env_data = list(),
  occ = data.frame(),
  stan_model = NULL,
  call = character()
)
```

## Arguments

- env_data:

  A (prefered named) list with environmental raster time series.

- occ:

  A data.frame

- stan_model:

  A stan fitted object slot. Default is NULL

- call:

  Call this function
