# Check environmental data list extent Check if all elements in the env_data list have equal extent

Check environmental data list extent Check if all elements in the
env_data list have equal extent

## Usage

``` r
check_envdata_ext(envData)
```

## Arguments

- envData:

  An list with environmental data time serires as elements.

## Value

If all the raster time serires are the same, return the crs string. If
not returns FALSE
